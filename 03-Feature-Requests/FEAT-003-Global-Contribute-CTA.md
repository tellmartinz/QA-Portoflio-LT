# [FEAT-003] Improve Contribution Discoverability: Global "Contribute!" CTA on Main Dashboard

**Project:** ForkMesh (Platform / UX)

**Current UX Problem:** The "Microjobs" section and core calls-to-action (submitting issues / opening PRs for rewards) are hidden behind the left-side navigation menu. Creating a new issue also requires navigating into a specific repository first, adding friction to the contribution process.

**Proposed Solution:**
- Add a clear, highly visible "Contribute!" or "Earn SOL" button directly on the main Home dashboard.
- Clicking it opens a quick-action modal (or redirects to an improved Microjobs page) where users can select "Create a New Repository" or "Submit an Issue" — with a repository dropdown for the latter, so users never have to leave the dashboard.
